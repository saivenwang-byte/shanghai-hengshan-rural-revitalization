# 23条业态A/B/C分级 — 以"客户会不会买单"为唯一评判标准

> A = 最小可行。投最少的钱，最快验证客户是否愿意付钱。  
> B = 完整版。A验证成功后，投入完整资源做透。  
> C = 灵活增减。不做单独投资判断，随整体成熟度自然生长。  
> 评判维度：客户买单意愿（主）+ 投资额/建设周期/运营复杂度（辅）

---

## 五、评判标准——"客户会不会买单"

| 业态 | 买单信号 | 观测方法 |
|------|---------|---------|
| 品米 | 周末场次满座 | 预订系统数据 |
| 咖啡3款 | 日销>30杯 | POS数据 |
| 邮花 | 月销>50套 | 邮驿销售数据 |
| 骑行 | 日租>10车次 | 来云吧租车数据 |
| 五感地图 | 领取率>80%到访者 | 邮驿发放数据 |
| 气味银行 | 月销>20套 | 邮驿+线上 |
| 集章 | 完成率>40%领取者 | 四点位盖章数据 |
| 邮驿 | 到访者>90%经过 | 热力感应数据 |

**如果A级数据不支持→B级暂缓→资源投向A级优化→直到数据反转。**
