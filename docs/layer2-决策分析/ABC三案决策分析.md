# 横山村乡村振兴项目 — 决策分析与A/B/C三案

> 文件性质：从数据到决策的投资分析报告  
> 前置阅读：Layer 1 基础研究母本

## 一、核心判断（基于基础盘数据推导）

### 1.1 横山村的三个核心优势

| 优势 | 数据依据 | 推导 |
|------|----------|------|
| **近郊高频可达** | 距市中心39km/45min，虹桥28km/35min | 适合周末高频消费，非低频远途度假 |
| **资产规模稀缺** | 10,000㎡+可盘活空间，4处核心资产，40+栋建筑 | 具备形成集群效应和规模经济的硬件基础 |
| **文化IP唯一性** | 黄公望隐居地、上海唯一环山型村落 | 可形成差异化定位，避免同质化竞争 |

### 1.2 三个核心约束

| 约束 | 影响 | 对策 |
|------|------|------|
| 原住民不能搬迁 | 不能做整村收储模式 | 采用"嵌入型"改造，保留村庄生活肌理 |
| 政府已有框架 | 不能推翻规划 | 在控规前提下做微调优化 |
| 基建条件未核实 | 水电污消防数据缺失 | A案最保守，待核实后B/C方可推进 |

## 二、A/B/C三案对比

> A/B/C不是"小/中/大"三档预算，而是三种战略路径。投资规模是战略选择的结果，不是原因。

### 2.1 方案定义

| 维度 | A案：存量提效型 | B案：系统重构型 | C案：分期进击型（推荐） |
|------|----------------|----------------|---------------------|
| **战略核心** | 接受现有框架，不对顶层设计做重大调整；重点做存量资产的功能提升和经营效率优化 | 重新定义项目定位，对空间系统和产业体系进行结构性改造；打造"环山而居·沪派江南"乡村目的地 | 接受B案长期方向，但利用现有资产分期推进；用最小投资验证市场，成功后逐步升级 |
| **规划调整范围** | 不调整控规，仅做微改造 | 建议调整部分控规边界（如停车、交通组织） | 前期不调规，后期根据运营数据申请微调 |
| **公共工程范围** | 道路修补、标识系统、基础景观 | 道路白改黑、河道整治、统一外立面、照明系统、智慧停车 | 分两期：一期同A案；二期根据招商情况追加 |
| **建筑改造面积** | 约4,500㎡（仅改造大院+来云吧部分空间） | 约8,500㎡（4个点位全面改造） | 一期3,500㎡，二期5,000㎡ |
| **新增设施** | 无 | 山脚门户广场、林下步道、南坡观景台、骑行补给站 | 一期仅山脚门户；二期林下步道+骑行站 |
| **产业系统** | 单体运营为主，轻量协作 | 统一品牌体系，全链条产业组织 | 一期单体+轻协作；二期统一品牌化 |
| **招商对象** | 本地餐饮、小体量民宿、咖啡店 | 头部民宿品牌（1-2家）、生活方式品牌、研学机构 | 一期同A案；二期引入品牌民宿 |
| **建设周期** | 12个月 | 24-30个月 | 一期12个月，二期24个月 |
| **政府投入（估算）** | 1,500-2,500万 | 3,500-5,000万 | 一期1,500-2,000万，二期2,000-3,000万 |
| **社会资本投入** | 500-1,500万 | 3,000-6,000万 | 一期500-1,000万，二期2,000-5,000万 |
| **年度运营成本** | 200-400万 | 500-800万 | 一期200-300万，二期400-600万 |
| **预期年收入** | 300-600万 | 1,200-2,000万 | 一期300-500万，二期800-1,500万 |
| **村集体年收益** | 50-100万 | 150-300万 | 一期50-80万，二期100-200万 |
| **成熟期能级** | 区域性休闲节点 | 上海市级乡村振兴目的地 | 逐步进阶到B案能级 |
| **核心风险** | ①差异化不足 ②招商吸引力弱 ③可能在竞品中沉没 | ①投资量大、回报周期长 ②招商压力大 ③政府审批复杂度高 | ①过渡期品牌形象不统一 ②二期资金存在不确定性 |

### 2.2 A/B/C 投资产出对比一览

| 指标 | A案 | B案 | C案（推荐） |
|------|-----|-----|-----------|
| 政府总投资 | 1,500-2,500万 | 3,500-5,000万 | 3,500-5,000万(分两期) |
| 社会资本拉动 | 500-1,500万 | 3,000-6,000万 | 2,500-6,000万(分两期) |
| 年运营收入 | 300-600万 | 1,200-2,000万 | 300→1,500万 |
| 年村集体收益 | 50-100万 | 150-300万 | 50→200万 |
| 直接就业 | 30-50人 | 80-150人 | 30→120人 |
| 年吸引客流 | 15-25万 | 50-80万 | 15→60万 |
| 投资回收期(公共) | 5-7年 | 8-12年 | 6-10年 |
| 成为示范村概率 | 较低 | 高 | 中→高 |

### 2.3 推荐方案：C案分期进击

**推荐理由：**

1. **风险可控** — 一期用最小投资验证横山近郊高频消费模型是否成立
2. **保留B案天花板** — 一期成功后，二期有完整的升级路径
3. **适应基建不确定性** — 水电污消防等硬条件需实地核实后方可确定改造范围
4. **兼顾政府诉求** — 一期产出可见成果，二期争取更高能级政策支持
5. **品牌方信心建立** — 首期试运营数据可吸引更优质品牌

### 2.4 C案分期里程碑

| 时间 | 里程碑 | 关键指标 |
|------|--------|----------|
| 第1-3个月 | 完成资产权属+基建核实 | 全部待核实事项清单清0 |
| 第4-6个月 | 启动一期公共工程 | 横山大院+来云吧外立面完成 |
| 第7-9个月 | 一期招商完成 | 出租率60% |
| 第10-12个月 | 一期试运营 | 月客流>1万人次 |
| 第13-18个月 | 一期运营数据复盘 | 入住率/客单价/复购率达标→启动二期 |
| 第19-24个月 | 二期公共工程+招商 | 横山小学+横云山居开工 |
| 第25-30个月 | 全面运营 | 年客流>50万人次，成为上海市乡村振兴示范 |
| 第31-36个月 | 品牌升级+B案能级实现 | 年收入>1,500万，村集体年收益>200万 |
