# 横山二十四节气运营日历 — 全年时间操作系统

> 核心理念：横山不是"一年任何时候都一样"——它是720个不同的横山（24节气×早中晚×四点位×五感官）。  
> 黄公望画《富春山居图》花了三年，就是因为他要捕捉每个节气山水的细微变化。700年后，横山用同样的逻辑运营。
