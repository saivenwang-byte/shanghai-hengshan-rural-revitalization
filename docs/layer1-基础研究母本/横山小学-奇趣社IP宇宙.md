# 横山小学×学堂趣事录 — "黄公望小学·奇趣社"IP宇宙

> 核心理念：横山小学不只是一所被改造的旧校舍——它是一个"故事引擎"。  
> 每一个教室、每一条走廊、窗外的稻田、竹林里的风——都是故事发生的现场。  
> 线上的IP故事和线下的物理世界，在同一所小学里交汇。

---

## 一、IP转换：从日本到横山

### "学堂趣事录" → "黄公望小学·奇趣社"

| 维度 | 日本原版 | 横山版 |
|------|---------|--------|
| **地点** | 名古屋某小学 | 横山村·黄公望小学（原横山小学） |
| **社团** | 校园趣事观察社 | **黄公望小学·奇趣社** |
| **核心成员** | 伊藤光/加藤慧美/松本志郎/陆珣/陆瑆… | 保留人设骨架，中国化命名 |
| **故事引擎** | 7种推理范式×200案 | 保留7范式，增加"横山专题"：米旅/骑行/夜观/竹林/物种护照 |
| **社区长辈** | 葛西泉藏（70岁·社区记忆） | **黄爷爷**（70岁·横山村民·知道黄公望的故事） |
| **文化底色** | 日本校园文化 | **中国乡村小学 + 黄公望700年文脉** |

### 为什么要中国化？因为故事发生的地方不一样了

日本版的推理范式（日常之谜/科学推理/心理洞察）不需要改——推理是普世的。但**故事发生的土壤**必须换：

- 名古屋的校园怪谈 → 横山小学的"黄公望传说"
- 日本的校园文化 → 中国乡村小学的日常
- 日本的地域特色 → 横山的稻田/竹林/骑行/夜观/非遗

**故事还是那些故事——发生在哪里，就长成哪里的样子。**

## 二、横山小学作为"物理故事引擎"

### 学校的每一个空间都是一个故事场景

| 物理空间 | 对应功能 | 故事中的角色 |
|----------|---------|-----------|
| **东窗画室**（黄公望画室） | 艺术驻留+画疗+米纸画工坊 | "那扇窗每天早上有不一样的光——黄公望用它画了三年" |
| **大唐院落** | 顾绣教室+版画工坊+皮影小剧场 | "院子的每个角落都有一个700年前的故事" |
| **竹林边·声疗室** | 竹林音疗+颂钵 | "竹林里的风声，黄公望说是他最好的背景音" |
| **碾米坊**（原农机房） | 碾米体验+品米室 | "一粒米从稻谷到白饭，经过了哪些人的手？" |
| **稻田**（窗外） | 稻田观察+插秧+收割 | "窗外那块田，北坡第三块——米是甜的" |
| **环山路** | 骑行+夜骑 | "8km的闭环，每拐一个弯看到的山都不一样" |
| **南坡平台** | 四时窗+观星 | "这里是上海最近能看到银河的地方" |
| **"黄爷爷"的家**（李大爷家） | 社区记忆库 | "他知道横山每一条路的来历——因为这条路是他爷爷修的" |

### 奇趣社的"案件"发生在这些真实空间里

| 卷 | 推理范式 | 故事舞台 | 横山物理体验 |
|----|---------|---------|-----------|
| 第1卷 | 日常之谜 | "竹林里的风为什么今天声音不一样？" | 竹林音疗·听风 |
| 第2卷 | 科学推理 | "北坡的米为什么比南坡的甜？" | 田块品鉴·南北坡对比 |
| 第3卷 | 心理洞察 | "黄爷爷为什么总在黄昏时坐在东窗前？" | 四时窗·黄昏观景 |
| 第4卷 | 历史推演 | "黄公望真的在这扇窗前画过吗？" | 黄公望AI导览·东窗 |
| 第5卷 | 观察推理 | "环山路第3个拐弯处，为什么总有一只白鹭？" | 环山骑行·观察站 |
| 第6卷 | 逻辑推理 | "那天晚上看到的星星，和700年前黄公望看到的是同一颗吗？" | 暗夜社区·星空观测 |
| 第7卷 | 空间推理 | "碾米坊的机器为什么今天声音不一样？" | 碾米坊·碾米体验 |

**每个故事都可以在横山实地还原。读完第2卷的孩子，周末来横山——真的去北坡和南坡各吃了一口米。"是真的！北坡的比较甜！"**

## 三、故事的核心定位——"小而全"的自我闭环宇宙

### 不是《名侦探柯南》，不是《哈利波特》——是《窗边的小豆豆》+《放学后的推理俱乐部》

| 维度 | 定位 |
|------|------|
| **读者年龄** | 小学2-6年级（桥梁书·从绘本到章节书） |
| **故事体量** | 每篇2,000-3,000字·每卷4篇·共50卷200篇 |
| **叙事调性** | 温暖、好奇、微推理——不血腥、不恐怖、不黑暗 |
| **核心主题** | "日常中的不寻常"——每一件"觉得奇怪"的事都值得观察 |
| **心理层** | 每个故事解决一个"小的心理问题"：不敢提问/害怕失败/不知道怎么交朋友/觉得别人都比我厉害 |
| **知识层** | 每个故事不知不觉带你进入一个知识领域：植物学/声学/心理学/天文学/食品科学 |
| **沟通层** | 每个角色的性格决定了他们怎么提问、怎么倾听、怎么表达——读故事的过程就是学习沟通的过程 |

### 为什么家长也会读

因为这个IP解决的是"真实的问题"——不是"谁是凶手"，是"为什么我不敢举手"、"为什么别人都觉得我奇怪"、"为什么我觉得自己不够好"。这些问题孩子有，家长小时候也有。**家长看到的是自己小时候没被解答的问题。孩子看到的是"原来有人和我一样"。**

## 五、横山小学的核心角色——不只是IP的发生地，是IP本身

**黄公望小学·奇趣社 = 中国版的"巴学园"**

不是《窗边的小豆豆》里的巴学园——是**横山版的巴学园**：

- 教室的窗户对着山，山每天在变
- 窗外是稻田，春天插秧、夏天绿浪、秋天金黄、冬天休耕
- 走廊尽头是一个大唐院落，院子里有竹子
- 竹林边有一间声疗室，能听到风穿过竹叶的声音
- 碾米坊就在隔壁，碾米机的嗡鸣是课间铃声的一部分
- 环山路从学校门口经过，下午四点有人骑车经过
- 每天晚上，学校的院子里皮影戏亮着一盏油灯

**这不是"建了一个学校"——这是"700年前黄公望在这里画画、70年前村民在这里上学、现在你的孩子在这里读故事、周末来这里当一天奇趣社员"。横山小学是时间折叠的地方。**

---

> **一句话**：横山小学不只是"黄公望画过画的地方"——它是"你的孩子在这里读到黄公望的故事，周末来这里成为故事里的一员"的地方。
