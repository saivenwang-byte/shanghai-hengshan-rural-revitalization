# 横山八种人格的一天 — 不同的人，不同的横山

> 黄公望的一天 = 给"想当黄公望的人"  
> 但不是每个人都想当黄公望。横山应该有八种人格，每种人格有一整套专属体验。

---

## 八种人格画像

| 人格 | 谁 | 核心需求 | 一句内心独白 | 消费力 |
|------|-----|----------|-----------|--------|
| 🏔️ **黄公望** | 30-50岁城市中产 | 独处·慢·自省 | "让我一个人待着" | ★★★★ |
| 👨‍👩‍👧 **探险家** | 4-12岁孩子的家庭 | 孩子开心·长知识·安全 | "爸爸这个是什么" | ★★★★★ |
| 📸 **记录者** | 20-35岁博主/文艺青年 | 出片·独特·可分享 | "这个发小红书必火" | ★★★ |
| 🚴 **破风者** | 25-40岁运动爱好者 | 路线·强度·社群 | "这条线你骑过没" | ★★★ |
| 🧘 **修复者** | 28-50岁压力人群 | 安静·疗愈·排毒 | "我不想思考任何事" | ★★★★★ |
| 🍚 **寻味者** | 30-55岁美食爱好者 | 独特·地道·故事 | "这个味道上海没有" | ★★★★ |
| 🎨 **朝圣者** | 艺术学生/文化爱好者 | 深度·真迹·技法 | "黄公望真的在这里画过" | ★★ |
| 🎉 **同游者** | 朋友/情侣/小团体 | 共享·轻松·好玩 | "我们下次还来" | ★★★★ |

## 🏔️ 黄公望的一天（独处者）

**到达**：一个人开车，把手机调成勿扰模式。

| 时间 | 地点 | 做什么 |
|------|------|--------|
| 09:00 | 横山邮驿 | 取五感地图。不跟任何人说话。 |
| 09:30 | 北坡竹林 | 一个人走雾境步道。没有人。只有雾和鸟。 |
| 10:30 | 横山小学·东窗 | 坐在"发呆窗"上看山。黄公望AI导览说了一句："山今天很安静。" |
| 12:00 | 横云山居 | 一碗饭。一个人。窗外是稻田。 |
| 14:00 | 品米室 | 5种米。慢慢嚼。品米师不说话——他知道你是来安静的。 |
| 16:00 | 山南平台 | 四时窗。秋窗正对金黄稻田。坐了一个小时。 |
| 18:00 | 横云山居·房间 | 泡澡。窗外是山。没有电视。 |
| 20:00 | 围炉 | 一个人。一杯米酒。一本《富春山居图》。 |

**带走**：气味银行·秋 + 横山邮花·全套收藏

## 👨‍👩‍👧 探险家的一天（亲子）

**到达**：一家三口。孩子一下车就跑。

| 时间 | 地点 | 做什么 |
|------|------|--------|
| 09:00 | 横山邮驿 | 孩子领到"物种护照"，大人领五感地图 |
| 09:30 | 林地 | 勇敢者道路12关——爸爸在下面扶，孩子在绳网上爬 |
| 10:30 | 李大爷家 | 孩子第一次从鸡窝摸出鸡蛋——"它是热的！" |
| 11:30 | 横云山居·厨房 | 用刚摸的鸡蛋+横山大米做蛋炒饭——孩子自己炒的 |
| 13:00 | 来云吧 | 爸妈喝咖啡，孩子在河边玩水踩石头 |
| 14:30 | 横山小学 | 米纸画工坊——孩子用自己做的纸画画。带回家。 |
| 16:00 | 环山步道 | 家庭骑行：爸爸载孩子骑一小圈，妈妈在后面拍照 |
| 17:30 | 横云山居 | 入住。孩子说："明天还能去喂鸡吗？" |

**带走**：物种图鉴本+贴纸 + 孩子自己做的米纸画

## 📸 记录者的一天（博主）

**到达**：两个女生，拖着装满衣服的行李箱。

| 时间 | 地点 | 做什么 |
|------|------|--------|
| 06:30 | 北坡竹林 | 雾境。拍了40分钟——换了三套衣服。光柱穿过竹林的时候连拍。 |
| 08:30 | 横云山居·餐厅 | 早餐摆拍——"横山一碗饭"俯拍，窗外的山入镜 |
| 10:00 | 山南·稻田 | 稻田艺术——从半山腰拍下去。发小红书："上海居然有稻田画" |
| 12:00 | 来云吧 | 日落咖啡位——提前占的。拍了咖啡+山+河道三重构图 |
| 14:00 | 横山小学 | 黄公望画室——拿着自己画的山水自拍。滤镜：元四家 |
| 16:00 | 米酒封坛 | 两人一起封一坛"闺蜜酒"。标签上写"2031年开"。拍照发微博。 |
| 18:00 | 环山路 | 夜骑——不是真骑，是推着车在LED路标前拍照 |
| 20:00 | 横云山居 | 暗夜观测——望远镜+星空。拍了猎户座发朋友圈："离上海45分钟的银河" |

**带走**：横山邮花·全套 + 气味银行·四季套装（"今天拍的每一张照片都有对应的气味"）

## 🚴 破风者的一天（骑行者）

**到达**：一个人，车顶架着Trek。

| 时间 | 地点 | 做什么 |
|------|------|--------|
| 08:00 | 来云吧 | 停好车，换骑行服。来云吧寄存+租车+检修。 |
| 08:30 | 环山8km | 热身圈。骑一圈，熟悉路况。 |
| 09:30 | 佘天昆22km挑战线 | 来云吧→佘山站→辰山→广富林→返回。1.5h。 |
| 11:00 | 来云吧 | 回来。洗澡（来云吧有淋浴间）。坐下喝杯冰美式——"骑完22km的第一口咖啡。" |
| 12:00 | 横云山居 | 午餐：高蛋白+本地食材。碳积分自动到账。 |
| 14:00 | 品米室 | 恢复时间——坐着品米，不耗体力 |
| 16:00 | 环山8km×2 | 傍晚再骑两圈——光线好、温度低、速度更快 |
| 19:00 | 来云吧·深夜食堂 | 和其他骑友拼桌。聊今天的路线、摔车经历、下次约骑 |
| 21:00 | 横云山居 | 入住。睡前用泡沫轴放松。明天早上再骑一圈。 |

**带走**：横山骑行地图（手绘）+ 反光手环 + 碳成绩单（"今天你省了5.4kg碳=骑了24km"）

## 🧘 修复者的一天（疗愈）

**到达**：一个40岁的女性，刚辞职。一个人。

| 时间 | 地点 | 做什么 |
|------|------|--------|
| 08:00 | 林地 | 赤脚步道——脱鞋走200m。碎石→草地→泥土→溪水。四种触感。 |
| 09:00 | 竹林 | 声疗——躺在竹林里听颂钵+风声+水声。1小时。哭了。 |
| 10:30 | 横山小学·香道室 | 唐代香道——闻五种香+学一个香方。带走一瓶复刻香。 |
| 12:00 | 横云山居 | 午餐：素食。一个人。 |
| 14:00 | 横山小学·画疗室 | 不是学画——是"用黄公望的笔法画你的情绪"。画完烧掉。 |
| 16:00 | 山南平台 | 四时窗。坐着。看山。没有手机。 |
| 18:00 | 横云山居·SPA | 米糠酵素浴+米面膜。60分钟。 |
| 20:00 | 横云山居·房间 | 泡茶。写信给一年后的自己。寄存在横山邮驿。 |

**带走**：唐代香方复刻套装 + 气味银行·冬 + 横山期货·"明年今天的新米"（给自己一个再来横山的理由）

## 🍚 寻味者的一天（美食）

**到达**：一对中年夫妻，去过50+家米其林。

| 时间 | 地点 | 做什么 |
|------|------|--------|
| 10:00 | 品米室 | 田块品鉴——5种米对比。北坡偏甜、南坡颗粒大。丈夫说："我第一次知道米的味道不一样。" |
| 12:00 | 横云山居 | 午餐："横山一碗饭"定食。七个小碟子——每个配一种不同的米。 |
| 14:00 | 来云吧 | 米主题咖啡馆——米乳拿铁（米浆代替牛奶）。"比燕麦奶好喝。" |
| 16:00 | 碾米坊 | 看碾米——稻谷进去，白米出来。碾好立刻煮了一小锅。 |
| 18:00 | 横云山居·酒吧 | 米酒品鉴——纯米酒/米酒莫吉托/米酒马提尼。三杯。 |
| 19:00 | 横云山居·餐厅 | 晚餐："横山夜宴"——七道米食料理。主厨每道菜讲30秒。 |
| 21:00 | 围炉 | 烤红薯+热米酒。和邻桌聊各自吃过的有意思的餐厅。 |

**带走**：田块品鉴迷你装 + 封坛米酒 + 兰笋酱（"回家自己做笋烧肉"）

## 🎨 朝圣者的一天（文化）

**到达**：一个美术生，带着速写本。

| 时间 | 地点 | 做什么 |
|------|------|--------|
| 08:00 | 横山小学 | 东窗打开速写本。画横山——用黄公望的构图法（AI导览教的） |
| 10:00 | 横山小学·展厅 | 看黄公望生平展——不是大事年表，是他的画论摘录+横山实景照片对比 |
| 12:00 | 来云吧 | 午餐。翻看横山小学的驻留艺术家作品集 |
| 14:00 | 米纸画工坊 | 自己造纸→用自造纸画横山→带走。花了整个下午。 |
| 16:30 | 山南平台 | 四时窗。临摹——眼前是横山，手里是富春山居图局部（印刷品） |
| 19:00 | 横山小学 | 横山雅集（如果今天有）。和驻留艺术家聊天。 |
| 21:00 | 横云山居 | 在房间里继续画白天没画完的那幅。 |

**带走**：自己造的自己画的米纸画 + 黄公望语录小册子 + 驻留艺术家复刻画

## 🎉 同游者的一天（社交）

**到达**：四个大学同学，毕业五年后第一次聚会。

| 时间 | 地点 | 做什么 |
|------|------|--------|
| 10:00 | 横山邮驿 | 四人各领一套集章本——比赛谁先集齐四个章 |
| 10:30 | 环山步道 | 徒步1.5小时。边走边聊——五年没见的八卦。 |
| 12:00 | 横云山居 | 午餐。拼桌。点了一堆菜——每道都拍照。 |
| 14:00 | 来云吧 | 下午茶+桌游。在露台上大笑着输了五子棋。 |
| 16:00 | 米酒封坛 | 四人一起封一坛"同学酒"——"2031年聚会时开。" |
| 18:00 | 环山夜骑 | 四人夜骑——有人不会骑，有人骑很快。互相嘲笑。 |
| 20:00 | 围炉 | 烤红薯+米酒。许愿："十年后再来。" |
| 22:00 | 横云山居 | 泡私汤。继续聊到凌晨。 |

**带走**：集章本+四枚印章 + 同学酒（封存） + 夜骑反光手环
