# 横山村交通路线分析 — 多方向客流行进图

> 中心点：上海市松江区佘山镇横山村（佘天昆公路中段）  
> 测算方式：高德/百度地图路径规划 + 非高峰时段

---

## 路线一：市中心方向（人民广场 → 横山村）

```
人民广场 → 延安高架 → G50沪渝高速(西行) → 佘山/天马出口 
→ 佘天昆公路(南行) → 横山村
```

| 节点 | 累计距离(km) | 累计时间(min) | 途经 |
|------|-------------|-------------|------|
| 人民广场 | 0 | 0 | — |
| 延安高架-G50入口 | 8 | 8 | — |
| 徐泾收费站 | 22 | 15 | — |
| 赵巷出口 | 32 | 22 | 路过奥特莱斯 |
| **佘山出口** | 40 | 30 | 佘山国家森林公园入口 |
| 佘天昆公路北段 | 42 | 33 | 佘山站(9号线) |
| **横山大院** | 45 | 38 | 到达首个点位 |
| 横云山居 | 47 | 42 | 最南端点位 |

## 六、途经地标与引流价值

| 方向 | 途经关键节点 | 引流价值 |
|------|-----------|---------|
| 市中心→G50 | 佘山国家森林公园(出口即见) | 1,570万游客的必经之路 |
| 虹桥→G50 | 奥特莱斯(赵巷出口) | 购物客流可转化为休闲客流 |
| 松江新城→地方道路 | 辰山植物园+广富林 | 200+180万游客顺路可达 |
| 青浦→G50 | 佘山站+佘山景区 | 9号线客流+自驾客流叠加 |
| 长三角→G60 | 天马山+天马乡村俱乐部 | 高尔夫+登山客群 |
