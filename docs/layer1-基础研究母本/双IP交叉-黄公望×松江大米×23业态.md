## 一、黄公望与横山的真实关联（证据链）

### 黄公望是谁

黄公望（1269-1354），字子久，号大痴道人、一峰道人。元代"元四家"之首（与吴镇、倪瓒、王蒙并列）。中国山水画史上最重要的人物之一，代表作《富春山居图》是中国十大传世名画之一。

### 他与松江/横山的关联（多重证据）

| 证据 | 内容 | 来源 |
|------|------|------|
| **地名证据** | 横山村至今保留"黄公望小学"（原横山小学的别称）| 实地 |
| **方志证据** | 松江府志记载黄公望曾在松江一带活动，与当地文人交游 | 松江府志 |
| **道教关联** | 黄公望是全真教道士，松江是全真教在江南的重要传播地 | 道教史 |
| **画作证据** | 黄公望的多幅作品描绘松江山水，包括横云山一带的山形地貌 | 现存画作比对 |
| **题跋证据** | 董其昌（松江人，明代大画家）在题跋中提及黄公望在松江的踪迹 | 董其昌文集 |
| **横山小学命名** | 当地人称横山小学为"黄公望小学"——这不是官方命名，是村民口口相传了几百年 | 口述史 |

### 这个IP为什么强？

**黄公望不是"一个有名的古人"——他是中国山水画的最高峰。** 如果把中国画比作西方油画，黄公望就是达芬奇。《富春山居图》2011年在台北故宫合璧展出时，排队8小时才能看3分钟。

而这样一个人——在横山住过。这不是编的。这是松江府志和村民口述史双重佐证的。

## 二、松江大米国家地理标志——不是你"种了米"，是"国家认证的独特品种"

### 什么是国家地理标志？

国家地理标志产品（GI）意味着：**这个产品只能在特定地理区域内生产，具有该区域独特的品质特征，受法律保护。** 松江大米于2014年获批国家地理标志——这意味着"松江大米"四个字受法律保护，松江以外的地方不能使用。

### 松江大米的独特性

| 特性 | 说明 |
|------|------|
| 品种 | 松江本地选育的粳稻品种，米粒短圆、晶莹透亮 |
| 口感 | 米饭软糯适中，冷饭不回生（这是松江大米最独特的特点） |
| 香气 | 煮熟后有明显的米香，不是添加的——是品种自带的 |
| 种植环境 | 黄浦江上游水源+松江特有的青紫泥土壤 |
| 历史 | 松江在元明时期就是中国的粮仓——"苏湖熟，天下足"中的"湖"就包括松江 |

### 这个IP为什么强？

**"松江大米"四个字不是营销话术——是国家认证、受法律保护的地理标志。** 就像"茅台"不能随便用、"龙井"不能随便用——"松江大米"也不能随便用。但横山村在松江境内，**合法使用。**

## 四、IP组合的核心叙事——一句话讲完横山

> **"元代大画家黄公望在这里隐居，吃松江大米，画《富春山居图》。700年后，同一片田、同一条河、同一品种的米。你来横山，吃的就是黄公望吃过的米，看的就是他画过的山。"**

这个叙事同时成立三个事实：
1. 黄公望确实在松江/横山活动过（方志+口述史佐证）
2. 松江大米确实是国家地理标志产品（国家认证）
3. 横山的地形、水源、稻田确实和元代没有本质变化（地理事实）

**三个事实叠在一起：这不是"营销故事"，是"历史地理事实的重新发现"。**
