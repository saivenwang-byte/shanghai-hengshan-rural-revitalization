# 松江大米国家地理标志详解 + 松江非遗资源全盘点

## 一、松江大米——国家地理标志保护产品

### 不是"松江种的大米"——是"国家认证的独特品种"

**2014年12月，原国家质检总局批准"松江大米"为国家地理标志保护产品。** 这意味着：

| 维度 | 具体含义 |
|------|----------|
| **法律保护** | "松江大米"四个字受《地理标志产品保护规定》保护。松江区以外的大米不得使用这个名称。 |
| **产地限定** | 只有松江区特定乡镇（佘山镇在其中）种植的特定品种才能叫松江大米。 |
| **品种限定** | 必须是松江本地选育的粳稻品种，不是随便什么稻种都行。 |
| **品质标准** | 必须达到规定的米粒长度/透明度/直链淀粉含量/胶稠度等理化指标。 |
| **种植规范** | 必须按照松江大米种植技术规程（包括水肥管理、病虫害防治等）生产。 |

### 松江大米的独特品质特征

| 特征 | 标准 | 通俗解释 |
|------|------|----------|
| **米粒外观** | 短圆形，长宽比≤1.8，米粒晶莹半透明 | 圆润饱满，不是长粒米 |
| **蒸煮品质** | 米饭油亮，软糯适中，有嚼劲不粘牙 | 不像糯米那么粘，不像籼米那么散 |
| **冷饭不回生** | 这是松江大米最独特的品质——米饭冷了以后不会变硬变干 | 日本寿司米的标准特质——松江大米天然就有 |
| **香气** | 有天然米香，不是添加的——是品种和土壤决定的 | 煮饭时满屋飘香 |
| **胶稠度** | ≥70mm | 米饭的口感软糯程度 |

### 这个 IP 有多强？

**国家地理标志 ≈ "农产品里的茅台/龙井"**。松江大米和西湖龙井、阳澄湖大闸蟹、五常大米是一个级别的认证。

**横山的特殊优势**：
- 横山村在松江区内 → 合法使用"松江大米"地理标志
- 横山元代就是松江的粮仓一部分 → 黄公望吃过的米 → 700年历史纵深
- 松江大米冷饭不回生的特质 → 可以做很多米制品（米糕/米酒/米布丁）而不会变硬

## 三、非遗的四层可结合度

### 第一层：可直接产业化的（高产业+高参与）

| 非遗 | 产品方向 | 体验方向 | 结合横山IP |
|------|----------|----------|----------|
| **松江顾绣** | 限量绣品（黄公望画作绣版）/丝巾/手帕/挂画 | 顾绣体验课（2h，绣一幅小画带走） | "绣一幅富春山居图" |
| **叶榭软糕** | 横山版软糕（松江大米为原料） | 软糕制作体验（1h） | "黄公望吃过的米做的糕" |
| **松江竹编** | 竹灯罩/竹篮/竹杯垫/竹茶具 | 竹编夜校（1天课程） | 横山竹+王师傅手艺=横山竹编品牌 |
| **松江剪纸** | 黄公望画作剪纸版/节气剪纸套装 | 剪纸工坊（30min，入门快） | "剪一幅横山" |
| **松江丝网版画** | 黄公望画作版画复刻/横山风景版画 | 版画工坊（1h，自己印） | "印一幅你看到的横山" |
| **泗泾豆腐** | 横山豆腐（本地大豆+横山水） | 豆腐制作（2h） | 搭配松江大米=豆腐饭 |
| **松江米酒** | 封坛米酒/品鉴套装 | 米酒酿造课（2天） | 黄公望的米酒 |

### 第二层：可作为活动内容但不宜大规模产业化的

| 非遗 | 在横山的应用 |
|------|-----------|
| **松江皮影戏** | 横山小学·夜场皮影——黄公望生平剧本（每月一场） |
| **花篮马灯舞** | 横山雅集·开幕巡游（每季一次） |
| **松江农民书** | 围炉夜话·方言讲故事（每周五/六晚） |

### 第三层：可为其他产品提供文化背书的

| 非遗 | 为谁背书 |
|------|----------|
| **余天成堂中药文化** | 唐代疗愈·药浴/气味银行·中药香囊/横山草药茶 |
| **松江棉纺织** | 黄公望画室·画布/横山文创·手织棉制品 |
