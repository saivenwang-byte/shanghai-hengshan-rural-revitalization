## 搜集要点

每个竞品至少搜集：
- 1张总体环境照（展示项目与周边自然关系）
- 1张核心建筑外景（入口/主立面）
- 1张室内/商业状态照（有人在使用的场景）
- 1张价格/设施信息截图（用于对标分析）

图片标注格式：
```
项目名称 | 位置 | 拍摄年份 | 定位 | 核心客群 | 可学机制 | 不适用条件
```

## Google Maps 使用方法

1. 点击上方链接 → Google Maps
2. 点击左侧项目名称 → 查看"照片"标签
3. 游客上传的实拍照片通常比官方图更有参考价值
4. 截图保存到 `docs/layer1-基础研究母本/competitor_images/`
