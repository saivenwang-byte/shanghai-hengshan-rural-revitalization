# 横山银行 — 积分兑换中枢+到达大厅

> 解决的核心问题：23条业态分布在4个点位，游客怎么玩？积分怎么兑？商家怎么结算？  
> 答案：横山大院·中央厢房 = 横山银行。所有人的第一站。

---

## 一、物理空间：横山大院·东厢房（约60-80㎡）

### 为什么是横山大院？

1. 它是游客进来的第一个点位——佘天昆公路进村第一站，停车场就在门口
2. 它是四合院，中央庭院天然是"集散广场"
3. 东厢房位置最靠停车场，不需要穿过院子就能到达——"到了就进，进来就走"

### 三个功能区在同一个空间里

| 区域 | 面积 | 功能 | 样子 |
|------|------|------|------|
| **A·到达台** | 进门正面 | 取地图/了解怎么玩/激活碳账户 | 一张2m长的木柜台，后面是横山大地图 |
| **B·积分兑换窗** | 进门右手 | 积分→抵用券/折扣确认/碳成绩单打印 | 像银行柜台——三个窗口，一个工作人员 |
| **C·活动预订板** | 进门左手墙面 | 今天有什么：品米/夜骑/疗愈/市集 | 黑板报风格，每日手写更新 |

### 动线设计

```
停车场 → 进东厢房 → A台取地图(1分钟) → B窗兑换积分(如有，30秒)
                   → C板看今天活动 → 出发去各点位
离村前 → 回到B窗 → 打印碳成绩单 → 兑换未用积分 → 离开
```

## 二、积分标准化：统一抵用券

### 积分→价值的统一汇率

**1分 = ¥0.28**（这样18分≈¥5，12分≈¥3.4，5分≈¥1.4——便于整数化券面值）

### 抵用券面值

| 券面值 | 需要积分 | 相当于 |
|--------|---------|--------|
| ¥5券 | 18分 | 骑1环 |
| ¥10券 | 36分 | 骑2环 或 骑1环+吃本地食材 |
| ¥20券 | 72分 | 拼车来+骑1环+吃本地食材 |
| ¥50券 | 180分 | 累计来3次 |

### 为什么是"券"而不是每个商家自己算？

- 所有抵用券由**横山银行统一印制**——防伪水印+当日日期章
- 游客到B窗，出示小程序里的积分→工作人员换成纸质抵用券
- 游客拿券去任何横山商户消费——咖啡/餐饮/住宿/购物/体验，通用
- 商户月底拿收到的券回横山银行结算——运营方按券面值95%兑付（5%为管理费）

**这样商户不用自己建积分系统——遵守规则很简单：'收券、月底来兑'。**

## 三、横山银行不只兑积分——它是"游戏说明书"

### 到达台的五感地图

每个新来的游客从A台免费领取一张"横山五感地图"——不是景点图，是感官图：
- 👁️ 红色标记：春/夏/秋/冬四时窗观景点
- 👂 蓝色标记：7个听音点
- 👃 绿色标记：气味银行+碾米坊
- ✋ 黄色标记：赤脚步道+树皮墙+溪水泡脚
- 👅 橙色标记：品米室+兰笋食堂+米酒封坛+深夜食堂

地图背面印着积分规则：做什么→赚多少→能换什么。一张纸搞定所有。

### 活动预订板（每日手写）

| 今天 | 时间 | 地点 | 剩余名额 |
|------|------|------|---------|
| 田块品鉴 | 14:30 | 横云山居 | 3/8 |
| 夜骑·灯光版 | 19:30 | 来云吧出发 | 12/20 |
| 围炉夜话 | 21:00 | 横云山居 | 满 |
| 明天·兰笋猎人 | 07:00 | 竹林 | 6/15 |

手写的好处：随时改、有温度、游客拍照发朋友圈。

## 四、标准游客流程（首次到访）

| 步骤 | 地点 | 时间 | 做什么 |
|------|------|------|--------|
| 1 | 东厢房·A台 | 2min | 取五感地图→激活微信小程序碳账户 |
| 2 | 东厢房·C板 | 1min | 看今天有什么→决定第一站去哪 |
| 3 | 各点位 | 4-8h | 骑行/品米/咖啡/散步/市集（自动积碳分）|
| 4 | 东厢房·B窗 | 1min | 小程序查积分→兑抵用券→去消费或带走下次用 |
| 5 | 离开 | — | 抵用券当次未用完，可下次再用（有效期3个月）|

**五个步骤，全程只在一个物理空间办手续——横山大院东厢房。离开后就自由了。**

---

## 五、商户结算规则

| 环节 | 怎么做 |
|------|--------|
| 游客支付 | 现金/微信/支付宝 + 抵用券（如果你有）。券=¥5/10/20/50，找零不补。 |
| 商户收券 | 每月25日之前把收到的券送回横山银行，填一张结算表 |
| 横山银行兑付 | 券面值×95%→次月5日前打到商户账户 |
| 5%管理费 | 用于：券印制成本+横山银行工作人员工资+小程序维护 |
| 券有效期的处理 | 游客券上印着日期章，过期15天后横山银行不兑付→避免商户事后拿旧券来套现 |

**商户不需要任何技术投入——收券、月底来换钱。简单。**
