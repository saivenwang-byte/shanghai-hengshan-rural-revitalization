## 二、城市分店——横山在上海市中心的"驿站"

### 不叫"横山餐厅分店"——叫"黄公望的茶寮"

元代横山脚下的三岔路口是一个驿站，往来松江府的商旅在此歇脚。700年后——横山在上海市中心开"驿站"。每一个分店，是一个通往横山的传送门。

### 首批四家分店——对应黄公望人生四个阶段

| # | 店名 | 位置 | 人物设定 | 空间设计 | 限定品 |
|---|------|------|---------|---------|--------|
| ① | **黄公望的书房** | 衡山路/武康路·梧桐区 | 30岁的黄公望——还在当小吏，每天下班后在自己的书房里偷偷画画 | 书架+旧书+暖黄灯光。墙上是黄公望早期习作（AI复原）。座位不多，很安静。 | "书房限定·桂花米酒"——黄公望30岁时最爱喝的 |
| ② | **黄公望的画室** | M50/西岸·艺术区 | 45岁的黄公望——已经辞官，每天在画室里待10小时 | 挑高空间+大面积白墙+可移动画架。墙上每月换展——一位当代艺术家的横山主题作品。客人可以在画架上自己画。 | "画室限定·墨香冷萃"——咖啡+食用竹炭粉，黑色。喝的时候像在喝墨水 |

### 分店的核心功能

| 功能 | 怎么做 |
|------|--------|
| **引流** | 每杯饮品附一张卡片："你喝到的米酒来自横山北坡第三块田。想去看吗？45分钟。" 卡片背面是前往横山的路线图 |
| **复购** | 集齐四家分店的章→免费换取横山一日体验（品米+咖啡+骑行） |
| **零售** | 每家分店售横山邮花、气味银行、封坛米酒——在市区就能买 |
| **内容** | 每家分店每月一个小型活动：书房店·读书会/画室店·速写课/山居店·茶会/渡口店·旅行分享 |

## 三、收集系统——让IP变得"可携带"

### 横山邮花·城市版

每一家城市分店有一枚**专属邮花**——但不是通用的¥5/10/20面值，是**"城市驿站纪念邮花"**。不能当钱用。纯收藏。

| 店 | 邮花画面 | 集齐奖励 |
|----|---------|---------|
| 书房 | 一盏油灯+一本书 | — |
| 画室 | 一支毛笔+一滴墨 | — |
| 山居 | 一棵树+一轮月 | — |
| 渡口 | 一条船+一座远山 | — |
| **集齐四枚** | — | 兑换横山一日体验（品米+咖啡+骑行+住宿折扣） |

### 横山纪念章·护照式

每个分店+横山村本部4个点位 = **8枚章**。集齐8枚→"横山终身旅人"称号+名字刻在横山小学的旅人墙上+终身来横山住店9折。

### 横山币·实体纪念币

每年发行一套4枚（春/夏/秋/冬），每枚¥38。材质：黄铜。正面：黄公望画作局部。背面：横山邮驿印章+"横山·2026"。第一年全套¥128。

## 四、人物叙事——黄公望不是"历史人物"，是"四个活着的人"

同一座山、同一个IP、同一个人——但他在30岁、45岁、55岁、60岁是完全不同的。每家分店对应他的一段人生。你走进不同的店，是走进他人生的不同阶段。

| 店 | 年龄 | 状态 | 你会感受到 |
|----|------|------|----------|
| 书房 | 30岁 | 每天上班，偷偷画画——不知道未来会怎样 | "我也是。上班/下班/不知道自己真正想做什么。" |
| 画室 | 45岁 | 刚辞官，每天都在画——不知道能不能画出名堂 | "我也想。但我不敢辞。" |
| 山居 | 55岁 | 隐居横山——终于活成了自己想要的样子 | "这是我想成为的样子。但还要等多少年？" |
| 渡口 | 60岁 | 离开——去画《富春山居图》。他知道这将是自己最重要的作品 | "他找到了。我找到了吗？" |

**四家店、四个人生阶段、四种精神状态。你去的不是"咖啡店"——你去的是"黄公望30岁时的焦虑/45岁时的决绝/55岁时的安宁/60岁时的释然"。**

## 五、商业逻辑——为什么要开分店

| 指标 | 数值 |
|------|------|
| 单店面积 | 60-120㎡ |
| 单店投入 | ¥50-80万（装修+设备） |
| 单店人员 | 3-4人 |
| 核心SKU | 5款IP饮品+3款米食+零售产品 |
| 客单价 | ¥45-88（饮品） |
| 盈亏平衡月 | 12-18个月 |
| 单店月营收 | ¥8-15万（预估·稳定期） |
| 单店为横山导流 | 每月约200-400人次（卡片引流） |
| 导流客户LTV | ¥500-1,500/人（到横山后的消费） |

**城市分店不需要盈利——它们是横山的"流量入口"。10家分店=每月2,000-4,000个被导流到横山的人。这些人到横山后的消费才是真正的利润中心。**

## 六、分店节奏

| 阶段 | 时间 | 做什么 |
|------|------|--------|
| **第0年** | 横山开业 | 来云吧+横云山居·酒吧先上线5款IP饮品，打磨配方 |
| **第1年** | 横山运营稳定 | 开第一家城市分店——"黄公望的书房"（衡山路/武康路）。试水市场反应 |
| **第2年** | 验证模型 | 如首店成功（单店月营收>¥8万），开第二家——"黄公望的画室"（M50/西岸） |
| **第3年** | 加速 | 山居店+渡口店。开始IP联名（品牌合作×黄公望IP饮品） |
| **第5年** | 全国 | 北京/杭州/成都……"黄公望的茶寮"开到全国 |
