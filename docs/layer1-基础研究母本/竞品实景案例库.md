## 案例1: 八十八亩田（松江·叶榭）

| 维度 | 内容 |
|------|------|
| **项目名称** | 八十八亩田 |
| **位置** | 松江区叶榭镇，距横山村约25km |
| **开业时间** | 2020年 |
| **项目定位** | 稻田民宿 + 乡村餐厅 + 自然教育 |
| **核心客群** | 上海亲子家庭、小红书打卡客群、企业小团建 |
| **经营规模** | 约20亩，民宿约10间，餐厅约60座 |
| **住宿价格** | ¥800-1,500/间夜 |
| **餐饮人均** | ¥150-300 |
| **值得学习的机制** | ①稻田IP化（稻田四季活动）②小红书自然流量好③农餐结合（稻田→大米→餐厅） |
| **不适合横山复制的条件** | ①体量太小不能支撑整体运营②高度依赖创始人个人IP③停车和交通条件一般 |
| **证据等级** | 🔶公开报道+OTA数据 |

## 案例2: 计家墩理想村（昆山·锦溪）

| 维度 | 内容 |
|------|------|
| **项目名称** | 计家墩理想村 |
| **位置** | 昆山市锦溪镇，距横山村约45km，车程50min |
| **开业时间** | 2017年逐步开业 |
| **项目定位** | 乡村共创社区 + 设计师民宿集群 |
| **核心客群** | 长三角中高端度假客、设计师圈子 |

| **住宿价格** | ¥1,200-3,500/间夜 |
| **值得学习的机制** | ①"新村民"机制（设计师/艺术家入驻）②统一运营+独立设计③社群活动运营（市集/工坊/音乐会） |
| **不适合横山复制的条件** | ①整村搬迁+统一收储模式——横山不能搬迁原住民②纯住宿业态为主，缺少餐饮/亲子配套③昆山政策与松江不同 |
| **证据等级** | 🔶媒体报道+OTA+实景图片可查 |

## 案例3: 莫干山民宿集群（德清）

| 维度 | 内容 |
|------|------|
| **项目名称** | 莫干山民宿集群（整体参考） |
| **位置** | 湖州德清县，距上海约160km |
| **核心参考意义** | 中国高端民宿发源地，但距上海车程>2h |
| **住宿价格** | ¥800-5,000+/间夜 |
| **行业规模** | 约800+家民宿 |
| **值得学习的机制** | ①"洋家乐"高端定位②裸心谷/大乐之野等品牌带动③政府统一规划+品牌独立运营 |
| **不适合横山复制的条件** | ①距上海太远（2h+ vs 横山45min）②莫干山独特的避暑气候③已成红海竞争 |
| **关键启示** | 横山优势在"近郊高频"而非"远郊低频"，应走"高频体验+中高端住宿"路线 |
| **证据等级** | ✅行业共识+大量公开数据 |

## 横山村的差异化机会（基于竞品分析）

| 竞争维度 | 周边竞品 | 横山优势 | 横山劣势 |
|----------|---------|---------|---------|
| 车程可达性 | 莫干山2h+，安吉2.5h+ | **45min直达上海市中心** | 缺少山区避暑气候 |
| 文化IP | 普遍缺乏 | **黄公望+唐宋+环山村落** | 知名度尚未建立 |
| 资产规模 | 大多为单体或小体量 | **10,000㎡+可盘活资产** | 改造投入较大 |
| 客群定位 | 低频远郊度假 | **高频近郊休闲** | 需要培育高频消费习惯 |
| 竞品密度 | 莫干山800+家内卷 | **松江乡村高端供给稀缺** | 周边配套成熟度不足 |
