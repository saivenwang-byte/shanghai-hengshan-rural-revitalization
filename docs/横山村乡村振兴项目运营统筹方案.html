    一、项目总述


    1.1 项目背景


    横山村位于上海市松江区，面积约5.1平方公里，横云山位于村落中央，村庄环山而居。作为"上海唯一环山型自然村落"、"九峰三泖核心区域"、"沪派江南节点"，横山村拥有稀缺的自然与文化资源标签。


    当前，政府已投入初步资金并完成了村庄资源推介和集体资产盘点。然而，面对上海周边乡村振兴项目的同质化竞争，政府亟需一个具有差异化、可落地、可持续运营的顶层方案。我方作为运营方，在政府既定框架下，提出本运营统筹方案，以衔接政府规划与市场落地。


    1.2 项目范围与定位


    项目定位： 以"环山而居·沪派江南"为核心IP，打造集精品民宿、特色农业、文创研学、数字乡村于一体的上海近郊乡村振兴示范项目。


    核心原则：

  • 不进行大拆大建，保护山体、田园、村庄肌理和原住民生活
  • 形成慢行、骑行、休闲、研学、民宿、农业体验等复合产品体系
  • 通过集体资产出租、入股、运营分成和本地就业形成持续收益
  • 建立数字导览、预订、农产品销售和乡村治理系统

    主体核心职责主要投入主要收益
    政府/村集体政策制定、总体规划、审批协调、资产授权、公共利益监管政策、土地房屋资源、行政协调、公共资金村集体增收、就业、资产增值、乡村治理和社会效益

    3.3 我方（运营方）的核心价值


    1. 顶层设计翻译官： 将政府宏观规划转化为可招商、可运营、可盈利的具体产品

    2. 招商筛选器： 把控品牌准入门槛，确保业态组合互补而非同质竞争

    四、功能定位与空间策划


    4.1 差异化竞争策略


    上海周边乡村振兴项目的核心痛点：

  • 业态同质化（千篇一律的民宿+咖啡+采摘）
  • 缺乏文化深度和IP辨识度
  • 单点运营无法形成集群效应
  • 重建设轻运营，建成后难以持续

    • 横山村的差异化定位：


    竞品常见做法横山村差异化方向
    单体民宿+简单餐饮四合院精品民宿集群 + 多元业态组合
    泛泛的"乡村体验"黄公望IP + 唐宋文化 + 沪派江南沉浸体验
    单一招商，各自为战统一运营统筹，品牌互补，集群联动
    传统线下导流"横山一点通"数字平台：导览+预订+电商+村务
    重资产自建轻资产运营，品牌方承担室内改造投资


    4.2 全村功能分区建议


    功能区核心空间目标业态
    核心接待区横山大院游客中心、乡村客厅、非遗工坊体验、精品咖啡/茶空间
    文化研学区横山小学（黄公望小学）研学基地、书院/图书馆、艺术驻地、小型展览、文创商店
    滨水休闲区来云吧（逅山咖啡）咖啡馆/轻餐、骑行驿站、小型市集、户外活动空间
    高端住宿区横云山居32栋高端民宿集群（10-15栋）、团建会所、亲子度假村、康养中心
    农业观光带40亩林地 + 田园采摘体验、农田景观、自然教育径、露营基地
    产业配套区原农机房、原针织厂房农产品加工展示、仓储物流、乡村创客空间

  • 目标客群： 所有到访游客、研学团、企业团建

    • 4.3.2 横山小学 — "黄公望书院"


  • 定位： 文化研学核心载体 + 艺术创作基地
  • 业态组合： 黄公望文化展厅 + 乡村图书馆 + 艺术驻留计划 + 研学教室 + 文创商店
  • 运营特色： 与美术学院合作设立写生基地，定期举办"横山雅集"文化活动
  • 目标客群： 学生研学团、文化爱好者、艺术创作者、亲子家庭

    • 4.3.3 来云吧 — "山前驿"


  • 定位： 骑行驿站 + 滨水社交空间

  • 运营特色： 与骑行俱乐部合作成为松江骑行线路固定站点
  • 目标客群： 骑行爱好者、年轻社群、周边居民

    五、运营方案


    5.1 招商策略


    招商原则：

  • 品牌互补，避免同质化竞争
  • 优先引入有乡村文旅运营经验的品牌
  • 设置3-6个月试运营考核期
  • 强制遵守统一的服务标准与品牌调性

    • 招商节奏：


    阶段时间招商目标出租率目标
    预热期第1-3个月锁定2-3家头部品牌（锚定品牌）20%
    集中招商期第4-8个月完成主要空间招商60%
    补充招商期第9-12个月补齐边缘空间和特色业态85%
    稳定运营期第2年起品牌优化迭代90%+


    招商渠道：

  • 文旅行业展会（上海旅游产业博览会等）
  • 民宿/酒店行业协会推荐
  • 社交媒体定向推广（小红书、抖音）
  • 松江区招商部门协同

    • 5.2 品牌准入标准


    1. 具备合法经营资质和良好的商业信誉

    2. 业态与所在功能区定位匹配

    3. 室内改造设计方案须经运营方审核

    4. 接受"横山村乡村振兴共同体"统一品牌体系

    5. 承诺最低经营年限（建议3年起租）

    6. 接受统一会员系统与数字预订平台


    5.3 运营管理机制


    日常运营：

  • 运营方设立"横山村运营管理中心"（设在横山大院）
  • 统一物业管理（保安、保洁、绿化、维修）
  • 统一市场营销（官网、社交媒体、OTA渠道）
  • 统一游客服务标准（投诉处理、安全应急）
  • 定期商户联席会（每月一次）

    • 收益管理：

  • 统一收银与会员系统
  • 按月结算租金与管理费
  • 按季度审计与绩效评估

    • 5.4 数字乡村平台 — "横山一点通"


    功能模块内容
    智能导览AR导览、语音讲解、路线推荐
    在线预订民宿、餐饮、活动、停车一体化预订
    农产品电商本地农产品在线销售与配送
    村务服务村民办事指南、村务公开、意见反馈
    数据分析客流分析、消费画像、运营报表


    5.5 市场营销策略


    品牌体系：

  • 主品牌："横山村乡村振兴共同体"
  • 子品牌："横山会客厅""黄公望书院""山前驿""横云山居"
  • 统一视觉识别系统（VI）和导视系统

    • 推广渠道：

  • 线上： 小红书种草、抖音短视频（利用已部署的MoneyPrinterTurbo批量生成）、微信公众号、OTA平台（携程/美团/途家）
  • 线下： 松江区旅游集散中心、佘山旅游度假区联动推广、旅行社合作
  • 事件营销： "横山雅集"文化季、"黄公望艺术节"、乡村马拉松/骑行赛

    • 5.6 社区共治


  • 成立"横山村乡村振兴理事会"（政府+村集体+运营方+商户代表+村民代表）
  • 村民参与：优先本地用工、农产品定向采购、民居风貌共建
  • 利益共享：运营收益的适当比例反哺村集体和村民

    建筑外立面统一改造政府/投资平台500-1,0004个核心点位

    运营方前期投入运营方200-500团队、方案、招商、营销


    公共部分总投资概算： 约 2,350-4,700 万元

    品牌方总投资概算： 约 2,000-5,000 万元

    项目整体拉动投资： 约 4,350-9,700 万元

    7.3 关键成功条件


    1. 政府明确授权运营方的统筹地位和决策权限

    2. 基础设施改造资金及时到位

    3. 首批锚定品牌的成功引入（决定市场信心）

    4. 数字平台的用户活跃度和预订转化率

    5. 社区关系的持续维护（村民参与度和满意度）


    7.4 风险提示与应对


    风险影响应对措施
    同质化竞争加剧招商困难，客流不足坚持IP差异化，定期迭代业态组合
    资金到位延迟基建工期拖后分期实施，优先完成核心点位
    品牌方经营不善空置率上升设置退出机制，保持品牌储备库
    政策变化补贴/支持力度下降多元收入模型，降低政策依赖
    村民参与度低社区关系紧张持续沟通、优先用工、利益共享
